KETECH CASH — prototype de site d'échange

1. Ouvrir index.html dans un navigateur pour voir le site.
2. Les taux de démonstration sont modifiables dans le code.
3. Pour WhatsApp, remplacer le numéro dans la fonction contactWhatsApp().
4. Pour un vrai service d'échange en ligne, ajouter un backend sécurisé, authentification admin, base de données, validation des transactions et conformité aux règles applicables.
